Typography

All type uses Goldman Sans. Headlines are set in Black (900) weight; body copy in Regular (400).

Headline — Goldman Sans Black
The quick brown fox jumps over the lazy dog
Body — Goldman Sans Regular

Quick Start

Favicon <head> snippet

<link rel="icon" href="/favicons/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="/favicons/favicon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="/favicons/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#36322f">

Import CSS tokens

@import url('./chorda-theme.css');

h1 {
  font-family: var(--font-headline);
  font-weight: var(--headline-weight);   /* Goldman Sans Black */
  color: var(--text-primary);
}

p {
  font-family: var(--font-body);
  font-weight: var(--body-weight);
  color: var(--text-secondary);
}

.card {
  background: var(--surface-base);
  border: var(--border-default);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-md);
  padding: var(--space-6);
}

JSON tokens (JS / React / etc.)

import tokens from './chorda-tokens.json';

const theme = {
  primary: tokens.color.primary.base,   // #36322f
  fontHeadline: tokens.typography.fontFamily.headline,
};
